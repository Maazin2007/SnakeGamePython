🐍 Python Snake Game (Tkinter)
A fast, colorful, and classic Snake Game built using Tkinter in Python.
Designed with clean code, simple structure, and smooth gameplay — perfect for learning GUI programming and game loops.

⭐ Features:

-> Smooth snake movement
-> Arrow-key controls
-> Food spawning on a grid
-> Score tracking UI
-> Self & wall collision detection
-> Game over screen
-> Fully customizable colors, size, and speed



🎮 Gameplay:

 -> Use the arrow keys to move the snake.
-> Eat food to grow and increase your score.
-> Avoid hitting walls or your own body!


🧠 What You Learn:
-> Tkinter canvas drawing
-> Keyboard event handling
-> Game loops using after()
-> Collision detection
-> Data structures for game state (lists of coordinates)
-> Simple OOP with Snake and Food classes



🚀 Run the Game
-> Clone the repo:
   git clone https://github.com/Maazin2007/SnakeGamePython.git
   cd SnakeGamePython

Run:
python3 snake.py


🛠️ Customize
Open the top section of the file:
GAME_WIDTH = 700
GAME_HEIGHT = 700
SPEED = 50
SPACE_SIZE = 50
SNAKE_COLOR = "#00FF00"
FOOD_COLOR = "#FF0000"
BACKGROUND_COLOR = "#000000"

You can change:
Game speed
Grid size
Colors
Window size
Snake starting length
